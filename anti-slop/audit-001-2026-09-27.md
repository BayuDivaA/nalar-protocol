# Audit UI extension NALAR

Mode: AFTER. Audit berbasis kode dan pengujian otomatis; belum ada uji klik di Chrome dengan wallet nyata. Arah visual: `Design.md`. Perubahan UI menunggu persetujuan nomor temuan.

Design read: popup intervensi keamanan untuk pengguna Web3, editorial-minimal dan tenang. Dial ENERGY 1 / RHYTHM 1 / MOTION 1.

1. **HIGH — R-36 / R-38: klaim sell tax melampaui bukti.** `extension/injected.js` pada fallback `getPrimaryRootCause()` menyebut kontrak *charges* persentase sell tax dan *preventing you from recovering funds*. Data yang tersedia adalah konfigurasi state, bukan bukti jumlah yang benar-benar dipotong saat menjual. Ubah fallback menjadi fakta konfigurasi dan dampak bersyarat.
2. **HIGH — R-27: state intent belum pasti ditampilkan sebagai mismatch.** `extension/injected.js` pada `createIntentVsActualComparison()` menganggap `security.intentMatch === false` sebagai mismatch sebelum memeriksa `comparison.overall === "UNCERTAIN"`. Hasil REVIEW yang belum bisa diverifikasi pun dapat tampil `DOESN'T MATCH`. Prioritaskan label `UNVERIFIED` untuk UNCERTAIN.
3. **HIGH — R-03: beberapa target sentuh di popup terlalu kecil.** `extension/popup.css` memberi status toggle 36px, Save 40px, dan tombol retry/theme lebih pendek lagi. Ini di bawah target 44px pada aturan responsif. Perbesar area interaksi tanpa membuat popup melebar.
4. **HIGH — R-35: QA visual/klik nyata belum terbukti.** Tes VM saat ini mencakup storage, network, dan explorer, tetapi tidak mengklik popup di Chrome pada lebar 320/360/400px atau mencoba alur wallet MetaMask/Rabby. Jalankan pemeriksaan tersebut sebelum menyebut UI siap rilis.
5. **MEDIUM — R-27: siklus data intent per situs belum lengkap.** `extension/popup.html` dan `extension/popup.js` menyediakan simpan intent, tetapi tidak memberi cara menghapus intent situs aktif atau menjelaskan bahwa intent dan data transaksi dikirim ke backend saat analisis. Tambahkan disclosure singkat serta kontrol hapus dengan feedback sukses/gagal.
